# Get Ur ATS - CV Builder

Welcome to **Get Ur ATS**, a simple, fast, and completely free tool designed to help you create a professional, ATS-friendly Curriculum Vitae (CV) in minutes.

> 🚀 **Live Demo:** [https://get-ur-ats.vercel.app/](https://get-ur-ats.vercel.app/)

## What is an ATS-friendly CV?

ATS stands for Applicant Tracking System. Many modern companies use this software to automatically scan and filter job applications. If your CV has a complex design, unique fonts, or unusual symbols, the system might fail to read your information, and your application could be rejected before a recruiter even sees it.

This website ensures your resume is structured perfectly so that the software can easily read your skills, education, and experience.

## Key Features

- **Live Preview:** See how your CV looks in real-time as you type.
- **Bilingual Support:** Easily switch the interface and CV headers between English and Indonesian with a single click.
- **ATS Validation:** A built-in checker will scan your CV to ensure it doesn't contain unreadable symbols, emojis, or lines that are too long.
- **One-Click PDF Export:** Download your finished CV as a perfectly formatted PDF instantly.
- **Plain Text Copy:** Need to fill out a long online application form? Copy your entire CV into plain text to easily paste it into company websites.
- **Privacy First:** Your data is saved locally on your own browser. We don't store or send your personal information anywhere.

## How to Use

1. Fill out your details in the form on the left side of the screen.
2. Watch your CV update automatically on the right side.
3. Check your **ATS Score** to see if your CV meets the software standards.
4. Click **Download PDF** when you're satisfied with the result!

## Running the Project Locally

If you'd like to run this website on your own computer:

1. Make sure you have Node.js installed.
2. Open your terminal in this project folder.
3. Install the required packages by running:
   ```bash
   npm install
   ```
4. Start the website by running:
   ```bash
   npm run dev
   ```
5. Open your web browser and go to `http://localhost:3000`.
